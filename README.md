# RecruitAI 🚀

An AI-powered HR Recruitment platform featuring intelligent resume parsing, semantic candidate-job matching, automated interview question generation, video interview screening, and recruitment analytics.

**Live Demo:** [hr-recruitment-beryl.vercel.app](https://hr-recruitment-beryl.vercel.app)  
**Backend API:** [hr-recruitment-backend-g3hi.onrender.com](https://hr-recruitment-backend-g3hi.onrender.com/api/health)

---

## ✨ Features

- ⚡ **Instant Demo Access** — One-click recruiter login for instant testing
- 🔐 **Google OAuth & Email/Password Auth** — Secure JWT authentication
- 📄 **AI Resume Parsing & Candidate Q&A** — Automatically extracts skills, experience, and contact info, with AI interactive Q&A
- 💼 **Job Postings Management** — Create, view, and manage open positions
- 🤖 **Semantic Skill Matching** — AI-driven match score calculation between candidates and open jobs
- ❓ **AI Interview Question Generator** — Tailored interview questions based on candidate resume and job requirements
- 📹 **Video Interview Screening** — Candidates record/upload video responses with AI feedback analysis
- 🎯 **AI Interview Analysis** — Confidence rating, speaking skills evaluation, and response transcript
- 📧 **Automated Email Delivery** — Sends interview invitations and scheduling links via SMTP
- 📊 **Analytics Dashboard** — Visual pipeline tracking candidate distribution and skill metrics

---

## 🛠 Tech Stack

**Frontend:** React + Vite + Vanilla CSS + Lucide Icons + Google OAuth  
**Backend:** Node.js + Express + Mongoose + JWT + Bcrypt  
**AI / LLM:** Groq API (Llama 3.3) + Google Gemini AI  
**Hosting:** Vercel (Frontend) + Render (Backend)  
**Database:** MongoDB Atlas

## 📖 How It Works

1. **Upload Resume**: Recruiter uploads candidate resume (PDF) → AI parses skills, contact info, and experience.
2. **Post Jobs**: Recruiter creates a new job listing with required skills and experience.
3. **Match & Generate Questions**: System calculates AI match score and generates tailored interview questions.
4. **Schedule & Video Screening**: Recruiter requests a video interview → Candidate receives email link to record response.
5. **AI Analysis**: AI evaluates candidate video responses for confidence, communication, and key answers.
6. **Hire**: Recruiter reviews candidate insights on the dashboard and makes hiring decisions.
